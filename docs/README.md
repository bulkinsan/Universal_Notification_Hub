## Правила, которые нельзя нарушать

Три правила, соблюдение которых экономит месяцы работы потом.

### 1. SQL живёт только в репозиториях

В маршрутах и сервисах SQL не пишется. Маршрут читается как список шагов: проверить → вызвать сервис → ответить. Смена базы — правка одного слоя, а не 40 маршрутов.

### 2. Дисциплина диалектов

Запрещено то, что есть только в SQLite: автоинкремент, `datetime('now')`, специфичные типы. Идентификаторы и время генерируются в коде.

Нарушение в одном месте сделает переезд на PostgreSQL переписыванием. Подробнее — [ADR-0001](decisions/0001-sqlite-first-postgres-later.md).

### 3. Тесты обязательны

Каждое решение с нетривиальной логикой покрывается тестом, проверяющим именно его. Три критических бага этого проекта прошли незамеченными, потому что соответствующих тестов не было.
