# Universal Notification Hub

Универсальный бэкенд уведомлений. Проект создан для сервисов (банков, соцсетей и т.п.), которые потеряли возможность отправлять push-уведомления через APNs, но хотят продолжать доставлять свои уведомления пользователям.

Как это работает: сервисы-отправители шлют уведомления в наш бэкенд через API, а бэкенд доставляет их людям по подходящим каналам — на веб (PWA), а в перспективе и на мобильные устройства (iOS/Android). Клиенты подключаются к бэкенду через API и разрабатываются отдельно, по документации бэкенда.

```
                         ┌────────────────────────────────────────────┐
                         │                БЭКЕНД                      │
                         │  Node.js + Express + SQLite (→PG потом)    │
                         │                                            │
  Источник (банк,        │  POST /api/v1/notify  (X-API-Key)          │
  соцсеть)  ─────────────┼─►  принимает уведомление                  │
                         │                                            │
                         │  ФАН-АУТ (по подписчикам, по каналам):     │
                         │    • web    → Web Push (VAPID)             │
                         │    • mobile → WebSocket (планируется)      │
                         │                                            │
                         │  GET /api/v1/notifications?user_id=        │
                         │    история для клиентов (оффлайн-подтяжка) │
                         │                                            │
                         │  /api/v1/admin/* (JWT) — админка:          │
                         │    источники, API-ключи, статистика        │
                         └──────────────┬──────────────┬─────────────┘
                                        │              │
                    ──── Web Push ──────┘              └──── WebSocket ────
                              │                              │
                   ┌──────────▼────────┐          ┌──────────▼───────────┐
                   │  PWA (веб)        │          │  iOS / Android       │
                   │  /pwa (демо)      │          │  нативные клиенты    │
                   └───────────────────┘          └──────────────────────┘

   /admin (vanilla JS) — админский веб-фронт (JWT в localStorage)
```
